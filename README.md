# Syntecxhub AI Chatbot Project 

##  Project Overview
This project is a professional-grade, rule-based AI Chatbot developed as part of the **Syntecxhub Artificial Intelligence Internship (Week 2 Task)**. 

Moving beyond a simple command-line interface, this version features a modern **Graphical User Interface (GUI)** designed for a seamless user experience. It handles user intents, answers domain-specific questions about Syntecxhub, and maintains a persistent log of all interactions.

##  Key Features
*   **Modern Dark-Mode UI:** A sleek, developer-friendly interface built with Python's `Tkinter` library.
*   **Interactive Quick Replies:** One-click buttons for common questions like "What is Syntecxhub?" and "Internship details."
*   **Intelligent Pattern Matching:** Uses Regular Expressions (`re`) to understand varied user greetings and queries.
*   **Automated Conversation Logging:** Every interaction is saved with a precise timestamp to `chat_history.log`.
*   **User-Centric Design:** Clean typography and high-contrast visuals for better accessibility.

##  Tech Stack
*   **Language:** Python 3
*   **GUI Framework:** Tkinter
*   **Logic:** Regex Pattern Matching
*   **Data Storage:** File-based logging (`.log`)

##  File Structure
*   `chatbot.py`: The main application script containing the UI and bot logic.
*   `chat_history.log`: Automatically generated file storing your conversation history.
*   `README.md`: Documentation for the project.
